## 核（確定・案A 逆転型）

**天武は、本来の後継者だったのに外されて、実力で皇位を取り戻した天皇。実在は確か。**
**もし壬申の乱に負けていたら、正当な後継者ではなく「反乱者」で終わっていた。**

## 読み上げ文（確定版・目安64秒）

**[1｜0-3s フック／冒頭テロップ：「実は後継者から外された天皇」]**
天武天皇って、じつは、次の天皇のはずだったのに、外された人なんだ。
（変更：歴史書のフックを外し、逆転型に差し替え）

**[2｜3-13s 背景]**
天武は、天智天皇の弟、大海人皇子。もともと、次の天皇と目される皇太弟だった。でも天智は、息子の大友皇子を太政大臣にして、あとを継がせようとした。身の危険を感じた大海人は、出家して、吉野にこもったんだ。
（変更：皇太弟の立場と、大友を太政大臣に据えた流れを追加）

**[3｜13-22s 挙兵]**
672年6月、大海人は吉野を出て、東の美濃へ向かった。不破の道をふさいで、東の国々の兵を、味方につけたんだ。
（変更なし）

**[4｜22-30s 決戦]**
最後は、近江の瀬田橋の戦い。敗れた大友皇子は、自ら命を絶った。乱は、およそ1か月で決着したんだ。
（変更なし）

**[5｜30-39s 即位]**
勝った大海人は、飛鳥で即位して、天武天皇になった。外された後継者が、自分の手で皇位を取り戻した形だね。「天皇」という呼び名が、確実に使われていたとわかるのも、この時代の木簡から。
（変更：「国の歴史書づくりを命じた」を削除し、逆転の着地を追加。木簡の一文は現状の言い方のまま）

**[6｜39-47s IF検証]**
もし、壬申の乱に負けていたら。大友の系統が続いて、天武は、皇位を奪いにいった反乱者として、終わっていたはず。
（変更：歴史書の IF を外し、逆転型に差し替え）

**[7｜47-53s 判定]**
判定。天武天皇は、本来の後継者だったのに外されて、実力で皇位を取り戻した、実在が確かな天皇だよ。
（変更：確定した核の文で判定）

**[8｜53-58s 二択]**
君はどっち派？
A 正当な後継者派
B 実力で奪った派
コメントで教えてね。
（変更：対立型に差し替え。締めの順をシリーズ従来型に）

**[9｜58-64s 登録＋締め]**
次回も古代史のもしもを検証していくから、チャンネル登録お願いします。
以上、あった？なかった？古代史でした。

※二択の「派」は読みで「ハ」
