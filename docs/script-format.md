# 台本ファイルの書き方

`episodes/<名前>.yaml` を1つ書くと、その回の動画ができます。
ファイル名がそのまま回の名前になります（半角の英小文字・数字・ハイフン。例: `ep3.yaml`）。

見本は `episodes/sample.yaml` です。

## 全体の形

```yaml
タイトル: 第3話「〇〇が一番こわい」
公開: true          # true なら push のたびに書き出して Release に載せる
静止: 0.3           # 各セグメントの終わりに止める秒数（省略すると 0.3）

背景: オフィス
小道具:
  - { 種類: 椅子, x: 420 }
  - { 種類: 机, x: 620 }

登場人物:           # 先に書いた人ほど奥に描かれる
  上司: { 色: 赤, x: -150 }
  主人公: { 色: 黒, x: 480, ポーズ: 座ってタイピング, 最初から: true }

セグメント:
  - id: seg1
    内容: フック                 # タイミング表に載るメモ
    秒: 3                        # セグメントの長さ（最後の「静止」も含む）
    台本: 「ちょっといい？」      # タイミング表に載るメモ（画面には出ない）
    動き:
      - [0, 主人公, 座ってタイピング]
      - [1.2, 上司, 歩く, { 到着: 315, のち: 腕組み }]
      - [2.0, 主人公, 驚く, { 動き方: ため }]
    文字:                        # 画面に大きく出す文字（なくてもよい）
      - { 秒: 1.0, 文: "ちょっと／いい？", 色: 赤 }

サムネイル:
  セグメント: seg2
  秒: 2.5
  文字:
    - { 文: "〇〇が一番こわい", 位置: 上 }
```

## 動きの書き方

1行に `[秒, 誰, 何, { オプション }]` の順で書きます。秒はそのセグメントの頭からの秒数です。

- **ポーズ**（`指さし` `驚く` など）… その姿勢に移り、次のポーズや移動まで保ちます
  - 一覧は `docs/poses.md`（Release の `pose_catalog.png` で絵が見られます）
  - `手を振る` と `座ってタイピング` は、そのポーズのあいだ自動で動き続けます
- **移動**（`歩く` `走る`）… `到着:` の x 座標まで進みます。着いたら `のち:` のポーズ（省略すると `立つ`）
- **重ねる動き** … いまの姿勢に重ねます
  - `うなずく`（回数）・`首を振る`（回数）・`ジャンプ`（高さ）・`お辞儀する`・`謝る`
  - `震える`（強さ）… 次のポーズや移動まで続きます（`時間:` で長さを指定可）
- **登場 / 退場** … 人物を出す・消す（何もしなければ、その人の最初の動きから画面に出ます）

人物は止まって見えないよう、いつも小さく呼吸しています。

### オプション

| 書き方 | 意味 |
|---|---|
| `x: 300` | その位置でポーズを取る（画面の横幅は 0〜1080） |
| `向き: 左` | 向きを変える（右 / 左） |
| `時間: 0.5` | ポーズの切り替えにかける秒数（既定 0.3秒）／重ねる動きの長さ |
| `到着: 700` | 歩く・走るの行き先 |
| `速さ: 1.5` | 歩く・走るの速さの倍率 |
| `のち: 腕組み` | 歩く・走るのあとのポーズ |
| `動き方: ため` | ふつう / すばやく / ゆっくり / ため（逆に引いてから動く） / はずむ（行き過ぎて戻る） |
| `回数: 3` | うなずく・首を振るの回数 |
| `高さ: 200` | ジャンプの高さ |
| `強さ: 2` | 震えの強さ |

## 背景と小道具

`背景:` と `小道具:` は全体に書くほか、**セグメントの中にも書けます**（その場面だけ切り替わる。場面転換に使う）。

### 背景（壁側の飾りと床）

| 名前 | 中身 |
|---|---|
| 床 | 床の線だけ（既定） |
| なし | 何もなし |
| オフィス | 窓・壁掛け時計（17:59） |
| 会議室 | ホワイトボード・時計・窓 |
| 電車 | 吊り革・窓（外の景色が流れる）・ロングシート（そのまま座れる） |
| コンビニ | 天井の照明・商品棚2つ |
| 自宅 | カーテン付きの窓・額縁 |
| 屋外 | 遠くのビル・流れる雲・木・電柱 |

### 小道具

`{ 種類: 机, x: 620 }` のように書きます。x は左端。床に置くものは自動で床に立ちます。

| 名前 | 指定できること |
|---|---|
| 机（モニター付き）・会議机 | 幅 |
| 椅子 | 傾き |
| プリンター・紙束 | |
| 時計 | 時刻（"17:59"）、y。秒針が動く |
| 窓 | 幅、y |
| ホワイトボード | 幅、文（板書） |
| ドア | 開き（0〜1） |
| 棚・レジ | 幅 |
| ソファ・ベッド | 幅 |
| テレビ | 点く（true で画面がちらつく） |
| 自販機・観葉植物・ゴミ箱・木・電柱 | |
| コーヒー | y（机の上なら 1310）。湯気が動く |
| 書類の山 | y、数（枚数） |
| 段ボール | 幅、y |
| 吊り革 | 数 |

どの小道具も `前: true` で人物より手前に描けます（机の陰に隠れる等）。
見本は `scenery-demo.yaml`（Release には載せない）。

## 演出

動きと同じ行に `[秒, 誰, 演出の名前, { 時間: 1.0 }]` と書きます。`時間` を省くと演出ごとの長さ（0.3〜2秒）になります。

| 名前 | 付ける相手 | 見た目 |
|---|---|---|
| 汗 | 人物 | 頭から汗が飛び散る（あせり） |
| 冷や汗 | 人物 | 頭の横にしずくが1つ垂れる（気まずさ） |
| びっくり | 人物 | 頭の上に「！」がポンと出る |
| はてな | 人物 | 頭の上に「？」 |
| 怒り | 人物 | 頭の横に赤い怒りマーク（脈打つ） |
| 衝撃 | 人物 | 頭の周りにギザ線 |
| ドキドキ | 人物 | 胸のハートが脈打つ |
| キラキラ | 人物 | 頭の周りに星がまたたく（喜び） |
| どんより | 人物 | 頭の上に縦線がゆらゆら（落ち込み） |
| 集中線 | 人物 / 画面 | 外から中心へ向かう線。人物ならその頭が中心 |
| 揺れ | 画面 | 画面が揺れる（ズームはしない）。`強さ` で大きさ |
| フラッシュ | 画面 | 白く光る |
| 暗くなる | 画面 | 背景が暗くなって人物が浮く。`強さ` で濃さ |

見本は `effects-demo.yaml`（Release には載せない）。

## 文字

`{ 秒: 1.0, 文: "ちょっと／いい？", 色: 赤, 位置: 上, 大きさ: 170, 消える: 2.5 }`

- `／` で改行。横幅に収まるよう自動で小さくなります
- `位置` は 上 / 中 / 下（または `y: 600` で直接）
- `消える` を省略するとセグメントの終わりまで出ています
- 第2話と同じく、ポンと拡大して出て少し震えます

## 座標の目安

- 画面は横 1080 × 縦 1920。床の線は y=1500
- 椅子に座らせるときは、椅子の x ＋ 60 くらいに人を置く（例: 椅子 420 → 人 480）
- 画面の外から入るときは x を -150 や 1230 にする

## 書き出し

```
npm run episode -- sample      # out/sample/ に結合版・セグメント別・サムネイル・タイミング表
```

書き間違いがあると、どの行が何の理由でだめかを日本語で表示して止まります。
書き出し後に、フレーム数・解像度・音声トラックが無いことを自動で確かめます。
