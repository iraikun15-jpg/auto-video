# 本編テスト v4「東京破壊」制作メモ

- コンポジション: `KaijuV4`（`src/kaiju/v4/`）／ 1080×1920・30fps・H.264・AAC ステレオ
- 尺: 40.0秒（1200フレーム）
- 明るさ: 夕焼け（空は青紫→橙のグラデーション、主光源は低い角度の夕日）
- 怪獣モデル: v2（`src/kaiju/ModelV2.tsx`）をそのまま使用。追加したのは背びれの発光と、頭に熱線を付ける口だけ
- 生成: `node scripts/synth-kaiju-v4.mjs`（音）→ `npx remotion render src/index.ts KaijuV4 out/kaiju_v4.mp4 --gl=swangle`

## 場面ごとの秒数（`src/kaiju/v4/timeline.json`）

| 秒 | 場面 | 内容 |
|---|---|---|
| 0.0〜5.0 | 登場 | 1フレーム目から引きで海と街。怪獣が海から3歩で上陸、3.6〜4.9秒に短い咆哮 |
| 5.0〜15.0 | 進撃と破壊 | 6歩前進して通り道のビルを踏み潰し。10.2〜12.1秒に尾の一振りで背後のビルをなぎ倒す |
| 15.0〜25.0 | 熱線 | 15.0〜18.0秒に背びれが尾の先→頭へ青白くチャージ。18.0〜24.0秒に熱線で街を右から左へなぎ払い（赤い塔も切断）。着弾点は爆発＋炎上 |
| 25.0〜35.0 | 破壊の継続 | 炎の中を前進。27.6〜29.3秒に2回目の尾払い、29.4〜32.7秒に短いチャージと2.5秒の熱線。煙と火の粉が増え、画面全体が赤く染まる |
| 35.0〜40.0 | 締め | カメラが引いていき、35.9〜39.0秒に長い咆哮（＋余韻）。燃える街と怪獣のシルエット |

## 音（すべて自前合成、`scripts/synth-kaiju-v4.mjs`）
既存の音源ファイル・効果音・BGM は一切使用していない。素材はサイン波・ノコギリ波・矩形波・ホワイトノイズのみ。

| 音 | 合成方法 |
|---|---|
| 足音 | 周波数が 64→30Hz に下がるサイン波（重い低音）＋低域ノイズの打撃＋地鳴り。海の中では水しぶき（帯域ノイズ）を足す。着地フレームに同期 |
| 倒壊 | カットオフが下がっていくローパスノイズ（崩れる轟音）＋38Hz の低音＋砕ける粒（短い帯域ノイズを数十個ランダム配置） |
| 爆発 | 74→24Hz のサイン波の衝撃音＋閉じていくローパスノイズ＋パチパチ |
| チャージ | 70Hz→630Hz に上昇するノコギリ波の和音（トレモロが速くなる）＋上昇する帯域ノイズ＋電気のはぜる音 |
| 熱線 | 揺らぐ帯域ノイズの轟音＋55/110Hz の低いうなり＋高域の空気音 |
| 咆哮 | ピッチが揺らぐノコギリ波5本＋1オクターブ下の矩形波（喉のうなり）＋息のノイズ → 30〜45Hz の振幅変調（ガラガラ感）→ 3本のフォルマント（声道）フィルタで「アー」から「オー」へ → 歪み。高い金属的な倍音を少量。短（1.3秒）と長（3.1秒＋リバーブの余韻） |
| 環境音 | 風（ゆっくり揺れるローパスノイズ）、炎上後は炎のざわめきとパチパチが増える |
| 空間 | Schroeder 型リバーブ（コム4本＋オールパス2本）を各音に送り量を変えて付与 |

### ラウドネス
- 自前で ITU-R BS.1770 の積分ラウドネスを計算して -15 LUFS に正規化し、先読みリミッターでサンプルピーク -2 dBFS 以下に抑えた
- ffmpeg（ebur128）での計測値は下の「計測結果」を参照
- 音量の順番: 熱線・長い咆哮 ＞ 短い咆哮 ＞ 足音・倒壊 ＞ チャージ・環境音

## 映像の作り
- 街（`city.ts` / `CityView.tsx`）: 碁盤目の街区に箱型ビル約170棟＋赤い塔＋遠景のビル群。窓明かりは Canvas で描いたテクスチャを emissiveMap に使い、UV をビルの大きさに合わせて窓の大きさを揃えた
- 壊れ方は怪獣の動きから事前に当たり判定して決定（毎フレーム同じ結果）
  - 踏み潰し: 着地した足の下 → 一気につぶれて平たい瓦礫に
  - 尾払い: 尾の向きが建物の方向を横切った瞬間 → 根元の縁を支点に倒れながら沈む
  - 熱線: 着弾点の周り → 上部が切り落とされて落下、下部は炎上して黒焦げに。周囲は延焼
  - いずれも土煙と破片が出る
- 熱線: 頭の関節の中に円柱3層（白→水色→青）を加算合成で配置。着弾点は口の位置と向きから地面との交点を計算
- 炎は円錐の加算合成、煙と土煙は低ポリ球、火の粉は Points
- カメラ: キーフレーム補間＋怪獣の位置を少し遅れて追従。足音・熱線・咆哮に合わせて揺れる

## 重くて簡略化した箇所
- 水面は平面＋反射っぽい色のみ（実際の反射・波はなし）
- 炎・煙はパーティクルシミュレーションではなく、決まった形の繰り返し
- 影を落とすのは主光源1灯のみで、範囲は怪獣の周り（±32ユニット）だけ。炎の点光源は影なし
- 倒壊はあらかじめ決めた動き（物理演算ではない）。建物は破片に割れず、形のまま倒れる／つぶれる
- 地平線の空はCSSのグラデーション（3Dの空ではない）

## 計測結果（ローカル：CPU 4コア・GPUなし、`--gl=swangle`）
- レンダリング時間: **1026秒（約17分）** / 1200フレーム（1フレームあたり約0.86秒）
- 音の合成: 約7秒
- 出力: 1080×1920 / 30fps / H.264 + AAC 48kHz ステレオ / 40.0秒 / 約51MB
- ラウドネス（ffmpeg ebur128、完成MP4で計測）: **-15.2 LUFS**、トゥルーピーク **-1.7 dBTP**
- 区間ごと: 熱線 -11.6 LUFS、長い咆哮 -13.7、短い咆哮 -15.5、足音・倒壊 -20.8、チャージ -23.6
