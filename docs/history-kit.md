# 日本史キット（あった？なかった？古代史）

台本ファイル `history/<名前>.yaml` を1つ書くと、これまでの回と同じ切り絵の動画が1本できます（縦の Short も、横の長尺も）。
内容は、結合版（BGM・効果音入り）・軽量版・サムネイル・タイミング表です。

```
npm run history -- sample      # out/history/sample/ に納品物一式
```

- 書き間違いがあると、どの行が何の理由でだめかを日本語で出して止まります
- 書き出したあと、フレーム数・音声トラック・壊れたフレーム・ラウドネスを自動で確かめます
- 見本は `history/sample.yaml`（小野妹子の回）

## 縦（Short）と横（長尺）

台本の先頭に `画面: 横` と書くと、YouTube の通常動画向けの横 1920×1080 になります（書かなければ縦 1080×1920 の Short）。
場面の型・見た目・音は縦と同じ書き方で、配置だけ横長に組み直されます。

### 長尺の組み立て方（目安 8〜10分）

```
フック（5秒）→ タイトル（6秒）
→ 章（4秒）→ 紹介・語り … （1章 1〜2分）
→ 章 → 年表・地図・語り …
→ 章 → 対比・語り …
→ 章 → IF …
→ 章（結論）→ 判定 → まとめ
→ 二択 → 登録
```

- 4〜5章、1章あたり1〜2分。8分を超えると YouTube で途中に広告を入れられる
- ナレーションが長く続くところは「語り」（人物と部品を見せながら、要点の札をゆっくり貼る）。1場面 40〜60秒が目安
- 長い場面（20秒超）は、項目が場面の8割5分まで散らして出る
- 「章」を書くと、タイミング表に **YouTube のチャプター一覧**（`0:00 オープニング` / `0:11 第1章 名前の誤解` …）が入る。概要欄にそのまま貼れる
- サムネイルも横（1920×1080）になる
- 書き出しの目安：ローカル 4コアで 8分の横長が約40分（縦 1分の Short は約4分）
- 見本は `history/long-sample.yaml`（約8分・5章）

## 全体の形

```yaml
タイトル: 第11本「〇〇は実在したのか」

見た目:
  舞うもの: 忍冬唐草
  転換: 光背
  札の色: 紺               # 見出しの札・フックの板・A の札の色
  主役: { 種類: 聖徳太子, 色: 紺, ふち: 金 }
  夜: false                # true で夜の和紙（草薙剣回の紺の台紙）

音:
  楽器: 箏
  音階: 律
  速さ: 62                 # 1分あたりの拍
  鈴: false                # true でフックと「夢」の場面にガラスの鈴
  持続音: true
  鐘: true
  大きさ: -28              # LUFS

場面:
  - 型: フック
    秒: 3
    ...

サムネイル:
  文字: [聖徳太子は, 実在したのか]
  判子: 実在？
  部品: [{ 名前: 法隆寺, x: 540, y: 1240 }]
```

## 場面の型

どの型にも書けるもの：

- `秒`（長さ。最後の0.3秒は静止）・`内容`（タイミング表のメモ）・`見出し`（上の札）
- `人物`（省略で主役。`なし` で出さない。`{ 種類: 推古, x: 300, 大きさ: 0.6, 向き: 左 }`）
- `判子`（`男性？` か `{ 文: 摂政, 秒: 6, 丸: true, 色: 金 }`。複数なら並べて書く）
- `札`（下に出るひとこと。`{ 文: ..., 秒: 4 }`）
- `部品`（`[{ 名前: 法隆寺, x: 540, y: 1300, 大きさ: 0.8, 秒: 2 }]`）

| 型 | 書くこと | 画面 |
|---|---|---|
| フック | `大見出し: [1行目, 2行目]`・札・判子 | 0フレーム目から板を叩きつける（拍子木＋太鼓）。判子は0フレーム目に着く |
| 紹介 | `名前: { 大: 厩戸皇子, 読み: うまやどのみこ, 注: 聖徳太子は通称 }` | 縦書きの大きな名前、人物は左 |
| 年表 | `項目: [{ 年: 603年, 文: 冠位十二階 }, ...]`（1〜5個） | 縦の軸に年の札と出来事の札が順に貼られる |
| 地図 | `地点: [{ 名前: 難波, 経度: 135.5, 緯度: 34.68 }, ...]`（1〜6個）・`線: false` で線なし | 地点がすべて入るよう自動で寄る。朱の線で順につなぐ（九州〜東北の南部まで） |
| 箇条 | `項目: [文, 文, ...]`（1〜5個） | 札が順に貼られる。最後の札は見出しの色 |
| 対比 | `左: { 見出し, 項目: [..], 色, 質感: 記録 }`・`右: {...質感: 夢}` | 左右に2枚の紙。質感は 記録（方眼）／夢（藤色のもや） |
| IF | `史実: [..]`・`もしも: [..]`（各1〜4個） | 左に実線の史実、右に朱の点線の「もしも」 |
| 判定 | `判定: [1行目, 2行目]`・`金: 実在` | 2行の大きな判子＋金の丸判子 |
| 二択 | `A: [実在の, 改革者派]`・`B: [..]`（見出しの既定は「君はどっち派？」） | A・B の2枚の札、「コメントで教えてね」 |
| 登録 | （なし） | 八咫烏が登録ボタンをつつく・「お願いします」・チャンネル名 |
| タイトル | `大見出し: [1行目, 2行目]`（省略で台本のタイトル） | 題名の大きな板（長尺のオープニング） |
| 章 | `題: 名前の誤解` | 「第一章」の札＋章の題＋金の線。番号は自動 |
| 語り | `項目: [..]`（0〜6個）・部品 | 人物を大きく、要点の札をゆっくり貼る（ナレーションの長い区間） |
| まとめ | `項目: [..]`（1〜6個） | 朱の印つきの要点の列（見出しの既定は「まとめ」） |

項目の出るタイミングは自動（場面の前半〜6割に等間隔）。`秒:` を書けばその時刻に出る。

## 部品

日輪・八咫烏・白鳥・猪・剣・光る剣・鉄剣・銅剣・銅鐸・銅鏡・金印・巻物・隋への国書・法隆寺・社殿・高い社・宮殿・中国の宮殿・鳥居・古墳・塚・舟・酒の甕・虫めがね・雲・山・冠

回の見せ場になる新しい部品は、これまでどおり `src/<回>/parts.tsx` に作り、`src/history/scenes.tsx` の `PartView` と `names.json` に1行ずつ足すと台本から使えるようになる。

## 型に収まらない見せ場

キットの型で足りない場面（法隆寺が組み上がる、八岐大蛇がうねる等）は、これまでどおりその回だけの場面コンポーネントを書く。
その場合も、台紙・札・判子・音の作りはキットのものを使い回せる。
